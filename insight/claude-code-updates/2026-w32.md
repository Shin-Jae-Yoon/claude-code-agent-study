## 주요 기능 — 세션 간 메시지

내 Claude Code 세션들끼리 서로 메시지를 보낼 수 있다. Claude 가 `ListAgents` 도구로 다른 세션을 찾고 `SendMessage` 로 보낸다. 내가 시켜서 보낼 수도 있고, 한 세션의 변경이 다른 세션 작업에 영향을 줄 때 Claude 가 알아서 보내기도 한다. 오가는 건 **Claude 가 상대 세션을 위해 쓴 텍스트뿐**이고 대화 기록이나 파일은 넘어가지 않는다. 한쪽에서 알아낸 사실을 내가 다른 창에 다시 설명할 필요가 없어진다. macOS·Linux, v2.1.224 이상.

```text
Tell the session working on the payments API that users.name is now users.display_name
```

받는 세션에는 Claude 가 메시지를 읽은 뒤 `Message from` 줄이 뜬다(`Ctrl+O` 로 펼침). 닿을 수 있는 세션 목록은 `/list-agents`.

관련 문서: https://code.claude.com/docs/en/cross-session-messaging#message-another-session

## 주요 기능 — 자체 호스팅 환경(self-hosted environments)

클라우드 세션을 우리 조직 인프라 위에서 돌린다(Team·Enterprise 퍼블릭 베타). 내 머신이나 컨테이너에서 `claude self-hosted-runner` 를 띄우면 러너가 된다. 누군가 claude.ai·모바일·데스크톱 앱이나 `claude --cloud` 로 세션을 시작하면서 그 환경을 고르면, 세션이 우리 네트워크 안에서 실행되어 내부 서비스에 접근할 수 있다. 먼저 Owner/admin 이 [admin settings](https://claude.ai/admin-settings/cloud-environments) 에서 **Allow self-hosted environments** 를 켜야 한다.

```bash
claude self-hosted-runner setup
```

러너가 등록되면 admin settings 에 **Healthy** 로 표시된다.

관련 문서: https://code.claude.com/docs/en/self-hosted-environments-quickstart#set-up-an-environment-and-runner

## 주요 기능 — auto mode 가 기본 권한 모드로

8월 14일부터 Pro·Max·Team 플랜의 신규 세션 기본 권한 모드가 auto mode 가 된다. 내가 기본 모드를 직접 지정해 뒀다면 그대로 유지되고(일회성 전환 프롬프트를 수락할 때만 바뀜), 조직이 관리하는 기본값도 바뀌지 않는다. 모드는 언제든 바꿀 수 있다. 이미 적용된 변화로, auto mode 의 분류기 호출은 사용량 한도에 포함되지 않는다.

```json
{
  "permissions": {
    "defaultMode": "auto"
  }
}
```

관련 문서: https://code.claude.com/docs/en/permission-modes#eliminate-prompts-with-auto-mode

## 기타 변경

- VS Code 확장에 [Focus view](https://code.claude.com/docs/en/vs-code#extension-settings) 추가 — 턴마다 접히는 한 줄 뒤로 도구 활동을 감춘다. 커맨드 메뉴 또는 `Ctrl+Alt+F`(맥은 `Ctrl+Option+F`)
- 샌드박스 credential 파일에 [`mode: "mask"`](https://code.claude.com/docs/en/sandboxing#mask-credential-files) 지원(Linux·WSL2) — 샌드박스 명령은 sentinel 사본을 읽고 샌드박스 프록시가 egress 시점에 실제 값으로 치환한다. 마스킹에 `extract`, JWT 인식 `decode`, AWS SigV4 재서명 옵션도 추가
- 마켓플레이스가 플러그인을 [zip 아카이브](https://code.claude.com/docs/en/plugin-marketplaces#zip-archives)로 배포 가능 — 새 `archive` source 로 HTTPS 다운로드, SHA-256 핀 선택. git·npm 없이도 설치된다
- `/review` 가 [`/code-review`](https://code.claude.com/docs/en/code-review#review-a-diff-locally) 의 별칭이 되고, effort 레벨 없이 부르면 마지막에 쓴 레벨을 재사용한다
- [`/fork`](https://code.claude.com/docs/en/agent-view#copy-the-session-with-%2Ffork) 로 복사한 세션이 원본 체크아웃이 아니라 자기 워크트리에서 코드를 수정한다
- [`/plugin`](https://code.claude.com/docs/en/discover-plugins#install-plugins) 으로 설치한 플러그인이 안전한 경우 현재 세션에서 바로 활성화된다. 설치 요약이 `Plugin is now active.` 를 알리거나 `/reload-plugins` 를 안내
- 워크트리에서 코드를 고친 [백그라운드 세션](https://code.claude.com/docs/en/agent-view#how-file-edits-are-isolated)이 끝나기 전에 커밋·푸시하고, 필요한 경우에만 draft PR 을 열며, `CLAUDE.md` 의 git 지침을 따른다
- 세션당 서브에이전트 200개 상한이 제거됐다. 장시간 세션이 새 서브에이전트를 거부하지 않는다([동시 실행](https://code.claude.com/docs/en/sub-agents#concurrent-subagent-limit)·깊이 제한은 유지)
- 레포에 체크인된 설정으로는 [Remote Control 자동 연결](https://code.claude.com/docs/en/remote-control#enable-remote-control-for-all-sessions)을 켤 수 없다. `remoteControlAtStartup` 은 user 또는 managed 설정에서만 켤 수 있고, project·local 설정은 끄는 것만 가능
- [워크트리 격리](https://code.claude.com/docs/en/worktrees#how-claude-code-enforces-isolation)가 파일 편집뿐 아니라 메인 체크아웃에 닿는 Bash 명령과 git 리다이렉트까지 막는다. 모든 세션 유형과 그 서브에이전트에 적용
- Bash 명령이 권한 검사에서 자기 일부를 숨길 수 없게 됐고, 탭·비가시 유니코드 패딩으로 승인 다이얼로그에서 명령 일부를 가리는 것도 막힌다
- PreToolUse 자동 허용 훅이 요약·컴팩션 같은 Claude Code 내부 사이드 태스크에서 도구 제한을 우회하지 못한다
- [Ultraplan](https://code.claude.com/docs/en/ultraplan) 리서치 프리뷰가 제거됐다(`/ultraplan` 명령과 `ultraplan` 키워드 포함). 대신 plan mode 나 Claude Code on the web 사용
