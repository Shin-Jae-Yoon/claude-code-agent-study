## 주요 기능 — Claude Opus 5

Claude Code 의 기본 Opus 모델이 Opus 5 로 바뀌었다. Max, Team Premium, Enterprise pay-as-you-go, Anthropic API 와 Claude Platform on AWS·Amazon Bedrock·Google Cloud's Agent Platform 에서 기본값이다. Anthropic API 및 Max/Team/Enterprise 플랜에서는 [1M 토큰 컨텍스트 윈도우](https://code.claude.com/docs/en/model-config#extended-context)로 돌아가고, Bedrock·Agent Platform 에서는 1M 모델 variant 를 직접 골라야 한다. fast mode 도 Opus 5 로 이동해 $10/$50 per MTok 이다. v2.1.219 이상 필요.

```text
> /model claude-opus-5
```

관련 문서: https://code.claude.com/docs/en/model-config#available-models

## 주요 기능 — Claude Code Desktop 의 iOS 시뮬레이터 패널

macOS Desktop 앱에 iOS Simulator 패널이 붙었다(Pro·Max·Team 퍼블릭 베타). Claude 가 앱을 빌드·실행하거나 시뮬레이터에서 확인할 때 대화 옆에 패널이 열리고 기기 화면을 실시간으로 스트리밍한다. Claude 가 직접 탭하며 자기 변경을 검증하는 걸 지켜볼 수도, 내가 기기를 조작할 수도 있다. iOS 플랫폼이 설치된 Xcode 와 Claude Desktop v1.24012.0 이상 필요.

```text
> Build the app and run it in the simulator to check the onboarding flow.
```

관련 문서: https://code.claude.com/docs/en/desktop-ios-simulator#run-your-app-in-the-simulator

## 주요 기능 — Claude Security 플러그인

세션 안에서 멀티 에이전트 취약점 스캔을 돌리는 플러그인. 에이전트들이 아키텍처를 매핑하고 위협 모델을 세운 뒤 취약점을 찾고, 각 발견 항목을 다시 독립적으로 검증한 다음 `CLAUDE-SECURITY-<timestamp>/` 디렉토리에 리포트를 쓴다. 레포 전체뿐 아니라 브랜치 diff, PR, 단일 커밋만 대상으로도 스캔할 수 있고, 고른 항목만 검토된 패치로 만들어 준다(적용은 사람이 직접).

```text
> /plugin install claude-security@claude-plugins-official
```

설치 후 `/reload-plugins` 를 돌리고 `/claude-security` 로 스캔을 시작한다.

관련 문서: https://code.claude.com/docs/en/claude-security#scan-and-fix-your-codebase

## 기타 변경

- [`/code-review`](https://code.claude.com/docs/en/code-review#review-a-diff-locally) 가 자체 컨텍스트 윈도우를 가진 백그라운드 서브에이전트로 실행된다. 리뷰 작업이 내 대화를 오염시키지 않고 완료 시점에 결과만 도착
- `/verify`, `/code-review`, `/deep-research` 는 이제 사용자가 직접 호출할 때만 실행된다. Claude 가 스스로 띄우지 않음
- [이모지 shortcode](https://code.claude.com/docs/en/interactive-mode#emoji-shortcodes) 자동완성 — 프롬프트에서 `:heart:` 로 이모지 삽입, `:` 뒤 2글자 이상이면 후보 제안. `emojiCompletionEnabled` 로 끌 수 있다
- `context: fork` 스킬이 기본적으로 [백그라운드에서 실행](https://code.claude.com/docs/en/skills#run-skills-in-a-subagent)된다. frontmatter 에 `background: false` 를 주면 같은 턴에서 결과를 기다린다
- 한 세션의 동시 서브에이전트 기본 상한이 20개. `CLAUDE_CODE_MAX_CONCURRENT_SUBAGENTS` 로 [조정](https://code.claude.com/docs/en/sub-agents#concurrent-subagent-limit)
- `--max-budget-usd` 상한이 서브에이전트에도 적용된다. 한도에 닿으면 새 서브에이전트를 못 띄우고 실행 중인 백그라운드 서브에이전트도 멈춘다
- [`sandbox.filesystem.disabled`](https://code.claude.com/docs/en/sandboxing#disable-filesystem-isolation) 설정 추가 — 네트워크 egress 통제는 유지하면서 파일시스템 격리만 건너뛴다
- auto mode 에서 위험한 `rm`, 백그라운드 잡, 의심스러운 Windows 경로 검사가 더 이상 권한 다이얼로그를 띄우지 않고 auto-mode 분류기가 판단한다
- Bash 권한 검사가 더 많은 셸 형태에서 fail closed — 파일 디스크립터 리다이렉트, `[[ ]]` 비교 안의 Zsh 변수 첨자, 위험 옵션을 실행할 수 있는 `help`·`man` 호출, 10,000자 초과 명령
- [Fast mode](https://code.claude.com/docs/en/fast-mode) 가 Opus 4.7 을 더 이상 지원하지 않는다. `/fast` 는 Opus 5 와 Opus 4.8 에만 적용
- 오래 걸리는 도구 호출이 침묵하지 않고 주기적으로 진행 heartbeat 를 낸다
