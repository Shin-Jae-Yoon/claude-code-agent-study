# 인사이트 (Insights)

AI·클로드 코드·에이전틱 코딩 관련해 각자 얻은 인사이트를 메모장처럼 자유롭게 남기고 공유하는 공간입니다.
형식 제약 없음 — 짧은 메모, 링크 모음, 삽질 기록 무엇이든 좋습니다.

## 쓰는 법

- 파일명: `insight/yyyy-mm-dd_<이름>.md` (예: `2026-07-30_이홍섭.md`)
- 하루에 여러 건이면 한 파일에 이어 쓰기
- 좋은 인사이트는 모임에서 공유
