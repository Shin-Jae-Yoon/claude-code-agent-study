# 딥다이브 (Deep Dive)

`/mid-study-deep-dive` 로 만든 조사 문서를 모아 두는 곳입니다.

챕터 결과물(`chapters/chN/README.md`)이 **그 주에 확정한 정리**라면, 여기는 그 정리에서 출발해 **열린 질문에 현재 근거로 답하고, 노트가 낡거나 틀린 지점을 표시한** 기록입니다. 요약이 아니라 확장이므로 챕터 폴더가 아니라 최상위에 따로 둡니다.

## 문서 목록

| 주제 | 출발한 곳 | 조사 기준일 |
|------|-----------|-------------|
| [에이전트 스킬](./에이전트-스킬.md) | [ch3](../chapters/ch3/README.md) | 2026-08-12 |

> **조사 기준일을 반드시 확인하세요.** 각 문서의 "지금은 무엇이 달라졌나" 표는 조사 시점의 스냅샷입니다. 제품·API·기본값은 계속 바뀌므로, 기준일이 오래된 문서의 내용을 현재 사실로 인용하지 마세요. 다시 필요하면 같은 파일에 스킬을 다시 돌려 갱신하고 기준일을 올립니다.

## 쓰는 법

- 파일명은 **챕터 번호가 아니라 다룬 주제**로 짓습니다 — `deep-dive/에이전트-스킬.md` (`ch3.md` ✗)
  - 딥다이브는 챕터가 아니라 주제에 묶입니다. 챕터를 넘나드는 주제도 있고, 챕터와 무관한 주제도 있습니다.
  - 어느 챕터에서 출발했는지는 파일명이 아니라 위 표의 "출발한 곳"과 문서 첫 줄의 입력 링크로 남깁니다.
- 문서 첫 줄에 **조사 기준일과 입력**을 남기고, 새로 만들거나 갱신하면 위 표에 반영합니다.
- 같은 주제를 다시 조사하면 새 파일을 만들지 말고 **기존 파일을 덮어쓰고 기준일만 올립니다.** 과거 버전은 git 히스토리에 남습니다.
