# 탐구 렌즈

입력에 적합한 렌즈만 선택한다.

| 렌즈 | 질문 방향 |
|---|---|
| 동기 | 이 문제가 왜 생겼고 기존 방식은 무엇이 부족했는가? |
| 메커니즘 | 내부에서 어떤 상태, 도구, 컨텍스트가 오가는가? |
| 경계 | 어떤 조건에서 효과가 사라지거나 실패하는가? |
| 비교 | 나이브한 방식, 책의 방식, 현재 권장 방식은 어떻게 다른가? |
| 검증 | 성공을 어떤 로그, 테스트, 비용, 품질 지표로 확인하는가? |
| 안전 | 권한, 비밀정보, 프롬프트 인젝션, 파괴적 작업 위험은 무엇인가? |
| 확장 | 단일 사용자에서 팀·병렬·장기 실행으로 가면 무엇이 바뀌는가? |
| 역사 | 책 출간 뒤 명령어, 기본값, 아키텍처, 권장 패턴이 어떻게 변했는가? |
| 전이 | 다른 도구나 모델에서도 유지되는 원리는 무엇인가? |
| 반증 | 이 주장이 틀렸음을 보여줄 관찰이나 실험은 무엇인가? |
