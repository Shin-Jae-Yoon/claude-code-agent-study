# 공통 스킬 (Shared Skills)

각자 `members/`에서 만들어 온 스킬 중, **논의를 거쳐 추린 것들을 공통 스킬로 승격**해 이 폴더에 둡니다. 여기 있는 스킬은 이 레포에서 클로드 코드로 작업할 때 팀 전체가 함께 사용합니다.

## 구조

클로드 코드 프로젝트 스킬 규칙을 따릅니다.

```
.claude/skills/
  <skill-name>/
    SKILL.md      # 스킬 정의 (name, description + 지침)
```

## 승격 절차

1. 각자 `members/<이름>/`에서 스킬 제작
2. 모임에서 논의 → 공통으로 쓸 스킬 선정
3. 선정된 스킬을 `.claude/skills/<skill-name>/`로 이동
