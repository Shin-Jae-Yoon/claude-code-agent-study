# Study Zettelkasten

챕터별 팀원 정리본에서 발견한 주장, 질문과 인사이트를 챕터 경계를 넘어 연결하는 공통 지식 저장소입니다.

## 구조

```text
zettelkasten/
├── README.md
├── notes/       # 하나의 주장·질문·인사이트를 담은 원자 메모
├── maps/        # 관련 원자 메모를 주제별로 연결하는 탐색 지도
└── syntheses/   # 각 챕터 또는 입력 묶음의 합성 기록
```

## 운영 원칙

1. 원자 메모 하나에는 독립적으로 이해할 수 있는 주장이나 질문 하나만 담습니다.
2. 단순 키워드는 원자 메모 대신 태그나 주제 지도로 관리합니다.
3. 같은 인사이트가 다른 챕터에서 다시 등장하면 새 파일을 만들지 않고 기존 메모에 출처와 근거를 추가합니다.
4. 비슷하지만 다른 인사이트는 별도 메모로 만들고 관계를 설명하는 Markdown 링크로 연결합니다.
5. 관련 원자 메모가 3개 이상 모이면 `maps/`에 주제 지도를 만듭니다.
6. 모든 출처와 연결은 GitHub에서 이동 가능한 표준 Markdown 상대 링크를 사용합니다.

## 사용 흐름

```text
챕터별 팀원 정리본
        ↓
반복·강조·긴장·독창 인사이트 추출
        ↓
기존 원자 메모 갱신 또는 새 메모 생성
        ↓
원자 메모 간 연결과 주제 지도 갱신
        ↓
합성 결과 기록
```

제텔카스텐 생성과 갱신 규칙은 [mid-zettelkasten-synthesis](../.claude/skills/mid-zettelkasten-synthesis/SKILL.md) 스킬을 따릅니다.
